# Pengantar Next.js 16

Next.js 16 membawa banyak perbaikan dan fitur baru yang membuat pengembangan web menjadi lebih mudah dan performant.

## Fitur Utama

- **App Router** yang lebih stabil dan lengkap
- **Server Components** untuk rendering di server
- **Streaming** dan **Suspense** untuk UX yang lebih baik
- **Img Component** yang dioptimalkan
- **Middleware** yang lebih powerful

## Memulai

```bash
npx create-next-app@latest
```

Atau dalam proyek ini:

```bash
pnpm dev
```

## Tips & Trik

1. Gunakan `next/image` untuk images yang otomatis dioptimalkan
2. Manfaatkan `loading=` untuk lazy loading
3. Susun struktur folder dengan `page.tsx` untuk routing
